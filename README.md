# Folder Focus

Hide and show folders in the Obsidian file explorer to keep your workspace focused. Hide all folders, unhide all, hide specific ones, keep only specific ones, and perform bulk hide/keep operations.

## Features

- **Hide All**: Hide every folder in the file explorer.
- **Unhide All**: Restore all hidden folders.
- **Hide Specific**: Hide selected folders.
- **Keep Specific**: Hide everything except selected folders.
- **Bulk Hide / Bulk Keep**: Apply hide or keep to multiple folders at once.
- Lightweight and fast — no impact on vault performance.

## Usage

1. Install the plugin in your Obsidian vault.
2. Use the command palette to run Folder Focus commands.
3. Select folders to hide or keep as needed.

## Installation

### From the Community Plugins directory
1. Open Obsidian Settings.
2. Go to Community Plugins and disable Safe Mode if needed.
3. Click Browse and search for "Folder Focus".
4. Click Install, then Enable.

### Manual installation
1. Download `main.js` and `manifest.json` from the latest release.
2. Create a folder named `naoufal-folder-focus` inside `.obsidian/plugins/`.
3. Copy the downloaded files into that folder.
4. Reload Obsidian and enable the plugin in Settings > Community Plugins.
